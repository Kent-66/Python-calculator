## アプリ名
Tkinter Calculator

## 概要
PythonのGUIライブラリであるTkinterを使って作成した電卓アプリです。  
学習目的で作成しており、Tkinterを使ったGUIレイアウトの基礎やPythonの基本文法、関数、制御構文などの理解を深めることを目的としています。

## 主な機能
・四則演算  
・クリア機能

## 使用技術
・Python 3.14  
・Tkinter

## 実行方法
1.リポジトリをクローンする  
GitHubからソースコードをダウンロードします。

git clone https://github.com/Kent-66/Python-calculator.git

2.プロジェクトのフォルダに移動する

cd Python-calculator

3.アプリを起動する  
Python3.14がインストールされていることを確認し、以下のコマンドを実行します。

calculator-app.py
